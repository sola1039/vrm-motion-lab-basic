# VRM基础动作实验台

一个在本机浏览器运行的VRM骨骼调试与动作回放平台. 支持VRM 0和VRM 1, 自动读取模型的人形骨架与蒙皮关系.

## 启动

安装Node.js 22或更新版本. 在仓库目录运行:

```powershell
npm ci
npm start
```

打开http://127.0.0.1:8766/, 选择自己的VRM文件. 模型需要把贴图和缓冲数据嵌入单个文件. 也可以将模型放在assets/model.vrm, 点击"载入本地默认模型".

服务仅监听本机地址. 本地选择的模型由浏览器读取, 没有上传接口. 加载另一个模型时刷新页面即可.

## 基础功能

- 正面、背面和侧面预览, 轨道旋转与缩放.
- 自动骨骼映射, 选中关节的局部XYZ旋转, 单关节与整个人物复位.
- 标准骨架和关节转轴显示, 父子跟随与方向检查.
- 独立元音口型控制, 不支持的口型不显示.
- 导出当前姿态, 导入动作文件, 时间轴、暂停、原始关键帧步进和倍速回放.
- 非均匀时间戳插值, 四元数最短路径球面插值, 循环时追加0.2秒回接段.

点击"载入播放验证样例"可检查播放器. 样例由程序生成, 只用于验证回放行为.

## 动作数据

格式标识为vrm-basic-motion, 版本1. 使用米和秒, 四元数顺序xyzw. 骨骼旋转相对于标准人形骨架的参考姿态, 髋位置是相对参考髋位置的位移. 每帧完整保存已声明的通道, 首帧时间为0, 后续严格递增.

骨骼名使用VRM 1标准, 左右为人物自身的解剖学方向. 不同模型的比例和动作范围可能不同, 此平台不执行动作捕捉重定向或自然语言动作生成. 音频字段仅保留引用, 当前不播放音频.

## 检查

```powershell
npm test
node --experimental-test-coverage --test-coverage-include='motion/**' --test Temp/tests/*.test.mjs
```

自动检查覆盖数据校验、插值、播放时钟和模型输入限制. 骨骼方向检查是诊断提示, 对比例特殊或非标准参考姿态的模型需要人工核对.
